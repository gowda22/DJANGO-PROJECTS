# Student Management System

A beginner Django project to manage student records.

## Technologies
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Features
- Home, About and Contact pages
- Django Admin
- Add student records through Admin
- Display students on a webpage

## How to Run
1. Activate the virtual environment.
2. Install Django.
3. Run migrations.
4. Start the Django development server.
